# Referencia visual: SIGARD Administración v2

Maquetas de diseño (no son código de la aplicación). Cada archivo `.dc.html` es una pantalla:
Ingreso, Main (Inicio), Predictivo, Alertas, Reportes, Contenido, Cuentas.

Se usan solo como referencia de estructura, colores, tipografía y textos.
El marcado `<x-dc>`, `<sc-for>`, `<sc-if>` y el bloque `<script type="text/x-dc">` pertenecen
a la herramienta de diseño: NO copiarlos al proyecto. Implementar con React y el CSS del proyecto.
Los valores entre corchetes ([N], [código], [fecha]) son marcadores, no datos.
