# Procedimiento para estudiar viabilidad territorial

`tools/analyze_territorial_feasibility.py` permite describir cobertura, soporte
común, tendencias y concentración sobre derivados previamente autorizados.
Las pruebas del procedimiento usan únicamente matrices ficticias.

Un subtotal de radios conocidos no se presenta como total de ciudad. No se
rellenan etiquetas desconocidas ni se extrapolan subtotales. La comparación de
distribuciones requiere soporte común; la cancelación de errores al sumar no
demuestra capacidad predictiva ni estabilidad espacial.

Los resultados y conclusiones de fuentes privadas se conservan fuera de Git.
Este documento no propone una nueva etapa ni autoriza ejecución científica.
