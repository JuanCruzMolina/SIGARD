# Fuentes tipográficas locales

IBM Plex Sans (400, 500, 600, 700) e IBM Plex Mono (500, 600), estilo normal, subconjuntos
`latin` y `latin-ext`: los mismos pesos y rangos Unicode que la hoja de Google Fonts usada hasta F7a.
Se declaran en `src/fonts.css`; Vite las empaqueta con el sitio, sin pedir nada a otro origen.

- Fuente: archivos woff2 de Fontsource 5.3.0 (`@fontsource/ibm-plex-sans`, `@fontsource/ibm-plex-mono`),
  descargados una vez de cdn.jsdelivr.net el 25/11/2026; no se agregó ningún paquete npm.
